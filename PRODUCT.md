# PPSAI Cleaner

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop (Python / CustomTkinter; not a web surface).

## Product Purpose

Recover disk space with reviewable scans, selective cleaning, duplicate-file inspection, and verified directory migration.

## Users

Repository-documented audience: Windows developers, AI tool users, and digital designers.

## Capabilities and Constraints

Retain existing cleaning rules, memory immunity, persistent user locks, licensing, risk confirmation, duplicate-copy validation, and lossless migration / restoration. UI changes must not alter persistent storage locations or cryptographic identity. Scans and file operations run off the UI thread. No destructive operation starts automatically.

## Brand Commitments

User-approved name: PPSAI Cleaner. User-approved folded P symbol in silver and ice cyan, graphite dark presentation. User authorizes replacement of all software UI, interaction, and layout and requests a redesigned splash based on the first approved image.

## Operating Context

Existing entry point: client_app/main.py. Auxiliary windows: deep_ui.py, dedup_ui.py, migrate_ui.py. Existing engine modules remain the functional authority.

## Workflow Defaults

The user explicitly confirmed a cleaning workspace as the default home: scan, inspect results, then clean. Existing technology and Chinese copy are retained.
