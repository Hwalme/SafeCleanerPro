# PPSAI Cleaner 桌面界面

新版采用用户确认的折带 P 品牌，统一启动画面、窗口图标、主工作台、工具窗口及授权流程。

## 运行

在项目根目录双击 `PPSAI Cleaner.lnk`，或运行 `Start-PPSAI-Cleaner.cmd`。快捷方式使用本机已验证的 Python 环境；启动脚本使用当前环境中的 Python。入口为 `client_app/main.py`。

这两个入口运行新版源码。现有历史发布目录中的 EXE 不会因源码更新而自动更新；正式发布继续使用项目现有的受保护构建流程。品牌资源位于 `client_app/assets/brand`，兼容构建入口使用的 `logo.ico`、`splash_logo.png` 也已同步。

## 工作流程

- 空间清理与深度清理分开显示，默认进入空间清理；扫描后核对项目和所选容量，再明确执行清理。
- 搜索与排序保留项目选择；上锁和免疫项目不可勾选。
- 改变磁盘范围使旧扫描结果失效，需要重新扫描。
- 列表查看路径、细分路径选择及逐文件排除继续连接原有清理内核。
- 深度项目默认不选中，清理前需要核对项目列表并勾选确认。
- 去重支持范围添加、双击移除、历史记录、筛选与副本校验。迁移保留复制校验、回滚与迁回流程。
- 扫描、清理和辅助工具互斥；进行中的任务阻止冲突操作和提前退出。
- 授权二维码与网络检查在后台运行；错误在窗口内显示，手动授权仍经原有 RSA/HWID 验证。

## 视觉与键盘

石墨黑底、银白文字、冰青主操作、琥珀复核状态。逻辑窗口尺寸最低 1120×740，默认 1380×860，支持 Windows DPI 缩放。

`Ctrl+1` 空间清理；`Ctrl+2` 深度清理；`Ctrl+F` 搜索；`F5` 重新扫描。磁盘范围支持上一组/下一组，键盘聚焦盘卡后用 Enter 或空格切换；公共按钮支持键盘聚焦和触发。
