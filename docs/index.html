功能四

重复文件查重：同一份文件存了八遍？找出来，只留一份。

全盘扫描内容完全相同的文件（按内容比对，不是按文件名），自动分类、按大小排序， 支持按类型 / 体积 / 日期筛选。删除前逐一校验内容一致，保证每组至少保留一份。

🔍 内容级比对

逐文件内容相同才判定为重复，改名 / 挪位置的同一文件也能识别。

🗂️ 自动分类筛选

图片 / 视频 / 音频 / 文档 / 压缩包 / 安装包自动归类，按体积日期过滤。

🛡️ 删除有底线

系统目录自动排除；每组重复强制保留一份，防止误删唯一原件。
