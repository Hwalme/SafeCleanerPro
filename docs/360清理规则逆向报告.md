# 360安全卫士 PC版 清理规则逆向报告

> 目标：提取 360安全卫士「电脑清理」功能的清除规则与路径，供 safecleaner 开发参考
> 安装包：360安全卫士官方离线包 `https://down.360safe.com/setup.exe`（111,015,728 字节，2026-10-17 获取）
> 规则配置版本：`cleancfg.xml` ver 11.0.0.1190 / `tracesweeper.dat` ver 9.0.0.1184

## 一、清理引擎架构

```
360Safe.exe（主程序）
  └── sweeper/                        ← 清理引擎目录
       ├── 360clean.dll               ← 核心清理 DLL（垃圾扩展名硬编码）
       ├── TrashClean.dll             ← 垃圾清理
       ├── SysSweeper.dll             ← 系统清理规则引擎
       ├── TEngine.dll                ← 痕迹清理引擎
       ├── 360GarbageCleaner.exe      ← 独立垃圾清理程序
       ├── SysSweeperNew.dat          ← 系统垃圾规则库（196KB，强加密，未解出）
       ├── tracesweeper.dat           ← ★ 痕迹规则库（167KB，已解密→ trace_rules.json）
       ├── SoftCheck.dat              ← 软件检测规则（74KB，加密）
       ├── 360OKCleanNew.dat          ← 一键清理规则（63KB，加密）
       ├── WhiteList.dat              ← 白名单（2.7KB，加密）
       ├── cleancfg.xml               ← 明文：应用↔规则ID映射、回收站/智能清理配置
       ├── okctree.xml                ← 明文：一键清理分类树
       └── DesktopGC.xml              ← 明文：桌面清理分组
```

| 文件 | 内容 | 规模 |
|---|---|---|
| `rules/trace_rules.json` | 痕迹清理规则：浏览器/Windows/软件使用痕迹。每条含类型、目标路径、选项 | 232 组，910 条 |
| `rules/trace_categories.json` | 痕迹分类（IE/Firefox/Chrome/系统/办公/媒体等） | 13 类 |
| `rules/clean_categories.json` | 一键清理分类树（Cookie/垃圾/痕迹/注册表/插件） | 5 大类 20 小类 |

| `rules/junk_file_extensions.txt` | 垃圾文件扩展名（`*.tmp` `*.log` `*.bak`…） | 36 种 |
| `work/decrypt_syssweeper.py` | .dat 解密脚本（自同步流密码，已验证） | — |

### 规则类型分布（910 条）

| 类型 | 数量 | 说明 |
|---|---|---|
| Directory | 254 | 目录清理，如 `%LOCAL_APPDATA%\Google\Chrome\User Data\Default\Cache` |
| RegValue | 240 | 注册表值，如 `HKCU\Software\Microsoft\Internet Explorer\TypedURLs` |
| RegKey | 137 | 注册表键 |
| SQLite | 128 | 浏览器 SQLite（如 Firefox `places.sqlite` 按表/条件清理） |
| File | 116 | 指定文件，如 `cookies.sqlite`、`formhistory.dat` |
| IniSection/IniKey/XMLNode/TextFile | 30 | 配置文件节点 |

### 路径变量（safecleaner 需自行展开）

`%LOCAL_APPDATA%` `%APPDATA%` `%InstallPath%`（软件安装目录）
`%COMMON_APPDATA%` `%PUBLIC%` `%UserProfile%` `%DataFile1%`（Firefox profile 通配）等。

示例（Chrome 缓存）：
```
Directory|%LOCAL_APPDATA%\Google\Chrome\User Data\Default\Cache|(DeleteSubFolder=1)(IncludeSubFolder=1)
```

## 三、应用→规则映射（cleancfg.xml）

- 覆盖 75 款浏览器/影音软件，每款映射到若干 `sysid` 规则与 `softid`。
- 回收站保护扩展名（不删）：`.rar .cab .csv .xlsm .dwg .tif .cdr .vcf .wps .vsdx .ost .txt .gif .jpg .bmp .jpeg .png`
- 回收站清理阈值 512MB；单次清理最小体积 100MB。

## 四、未解出的部分

`SysSweeperNew.dat`（196KB，系统垃圾文件路径规则主库）使用强加密
（非流密码，entropy 8.0，已排除单字节密钥全空间），需 Windows 动态调试才能破解。
建议 safecleaner 先用已交付的 910 条痕迹规则 + 分类体系搭建框架。

## 五、给 safecleaner 的建议

1. **规则格式**：照抄 360 的 `类型|路径|选项` 三段式，JSON 存储，明文可维护、可云端更新。
2. **SQLite 清理**：浏览器历史/密码/表单存 SQLite，按表+SQL条件删（如 360 对 `moz_places` 的书签排除条件），比删文件更精细。
3. **回收站保护**：照抄 360 的 17 种保护扩展名。
4. **VolumeCaches**：360 复用了 Windows `HKLM\...\Explorer\VolumeCaches` 机制，可直接调用系统磁盘清理 handler。
5. **进程关闭**：清理浏览器前先关进程（360 维护了 75 个浏览器进程名表）。

## 六、逆向过程记录

- 安装包：官网 `down.360safe.com/setup.exe`；7z 解包（1323 文件）。
- 规则定位：`sweeper/` 目录；XML 明文直接解析。
- `tracesweeper.dat` 解密：从 `SysSweeper.dll` 0x1006cd95 逆向出自同步流密码
  `pt[i] = ct[i] ^ key; key = (key + pt[i] + 1) & 0xFF`，初钥 0x23，GBK→UTF-8。
- `SysSweeperNew.dat` 为另一种强加密，未解出（见 §四）。
